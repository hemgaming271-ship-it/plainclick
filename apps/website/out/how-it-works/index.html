How it works

A separate panel that runs a supported app's own commands. Nothing about the app itself changes.

The short version

  1. Open a supported app, for example Safari.
  2. Press your PlainClick shortcut (⌃⌥P by default).
  3. A small panel appears, naming the app it will control and showing clearly labelled buttons.
  4. Click a button. PlainClick asks that app to run the matching command from its own menu bar.

What's happening underneath

PlainClick uses the macOS Accessibility interface, the same documented system that assistive tools use. It finds the app's own menu command and checks whether the app says the command is enabled. Then it asks the app to perform it. It does not move your mouse, type keystrokes, inject code, or change system files. It doesn't need administrator access.

Before every click, PlainClick checks that the app shown in the panel is still the app in front. If you've switched apps, nothing is sent.

What it can't do

  • Change, shrink, hide, or restyle any app's own toolbar or buttons.
  • Remove transparency or “glass” effects anywhere in macOS.
  • Work with apps we haven't tested. Other apps get an honest “not supported” message.
  • Reclaim screen space. The panel is an extra window, so you can move it or hide it.

Permission

To press commands in other apps, macOS requires you to allow PlainClick under System Settings → Privacy & Security → Accessibility. PlainClick asks only when you turn on app control. It explains why first, and you can turn the permission off there at any time. PlainClick doesn't ask for Screen Recording or Full Disk Access.

Free alternatives worth trying first

macOS includes Reduce transparency and Increase contrast under System Settings → Accessibility → Display. They're free, built in, and change the look of the whole system. See our appearance guide.
