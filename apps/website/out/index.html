Full compatibility details ›

Private by design.

PlainClick does its work on your Mac, with one permission you can see and switch off.

Runs on your Mac

It reads only the menu commands of supported apps, locally. Documents, screen contents and browsing history never leave your Mac.

One clear permission

Accessibility, asked only when you turn on app control, with an explanation first. Revoke it any time.

No system changes

No admin password, no code injection, no changes to system files, and you never turn off Gatekeeper or SIP.

No tracking

No analytics and no ads in the app. Licensing sends only your key and your Mac's model name.

What leaves your Mac

Only when you activate or the app checks your licence.

Good questions.

Does PlainClick change how my apps look?+
No. It adds a separate panel next to the app. The app's own toolbar, buttons and macOS appearance stay exactly as they are.
Which apps does it work with?+
TextEdit, Finder, Safari and Calculator, with the actions listed on the compatibility page. Every other app gets an honest “not supported yet” message instead of guesses.
Why does it need Accessibility access?+
macOS only lets one app press another app's menu commands with this permission. PlainClick uses it on your Mac only, and you can switch it off any time in System Settings → Privacy & Security → Accessibility.
Is it a subscription?+
No. It's US$5.99 once, for PlainClick v1 and every 1.x update, on up to two Macs you own. There's a 7-day free trial first.
What if it isn't for me?+
Ask for a refund within 14 days, no reason needed. See the refund policy.
Will macOS ask before opening it?+
Builds are signed with PlainClick's own certificate but not yet notarized by Apple, so macOS asks you to allow it once, when you first install it, in System Settings → Privacy & Security → Open Anyway. The download page shows how. You never need to turn off Gatekeeper.
