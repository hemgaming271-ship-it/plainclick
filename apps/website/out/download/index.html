Download

Download PlainClick 1.0.0

  • Requires macOS 14 Sonoma or later. Runs on Apple silicon and Intel Macs.
  • SHA-256: be0919723e7242ee94d8fccbedae53d348984a91e1f8ad0722e65a636a7c6be7
  • Signed with PlainClick's own certificate, but not notarized by Apple. Apple charges developers a yearly fee for notarization, and we haven't paid it yet. That's why macOS asks you to confirm it, below. It doesn't mean Apple checked and rejected the app.

Install

  1. Open the downloaded PlainClick.zip. Your Mac unzips it into PlainClick.
  2. Drag PlainClick into your Applications folder.
  3. Open PlainClick from Applications.

The first time you open it

macOS shows a message like “Apple could not verify ‘PlainClick’ is free of malware” and won't open it. That's expected for apps that aren't notarized. Click Done, then:

  1. Open the Apple menu → System Settings → Privacy & Security.
  2. Scroll down to Security. You'll see “PlainClick was blocked…”.
  3. Click Open Anyway, confirm with your password or Touch ID, then click Open Anyway again.

You do this once, when you first install it. Later versions install from PlainClick's menu → Check for Updates… without this step (if you download a new version from this page, you'll need to do it again). It allows only PlainClick. Keep Gatekeeper and every other security setting switched on. You never need to turn them off for PlainClick. If you'd rather not do this, don't install it.

Optional check before opening: in Terminal, run shasum -a 256 ~/Downloads/PlainClick.zip and compare the result with the SHA-256 above.

Then

  1. PlainClick appears in the menu bar.
  2. Turn on app control when you're ready, and allow Accessibility access when macOS asks.
  3. Press ⌃⌥P (Control-Option-P) to show or hide the panel.

Older versions and release notes are on the releases page.
